# Free CELPIP Practice Tests (PDF)

Printable CELPIP practice tests from [CELPass](https://celpass.com): Listening, Reading, Speaking and Writing, each with answers. Free to download and print.

Every PDF is also a free test you can take online, timed like the real exam, at [celpass.com](https://celpass.com/celpip/practice-tests-pdf).

| Skill | Tests | What's in each PDF |
|---|---|---|
| [Listening](#celpip-listening-practice-tests) | 117 | questions, answer sheet, answer key with CLB chart and transcripts; play the recordings on the test's page |
| [Reading](#celpip-reading-practice-tests) | 132 | all four parts, answer sheet and answer key with CLB chart |
| [Speaking](#celpip-speaking-practice-tests) | 49 | Tasks 1-8 with real timings and an Excellent sample answer for each task |
| [Writing](#celpip-writing-practice-tests) | 56 | Task 1 email and Task 2 survey with real timings and an Excellent sample answer for each |
